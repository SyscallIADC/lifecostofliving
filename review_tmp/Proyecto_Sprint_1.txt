1. Objetivo
Desarrollar un proyecto multimódulo en Java que consuma datos de dos fuentes externas
(APIs y/o páginas web mediante scraping ) y los persista en una base de datos SQLite.
El proyecto está diseñado para trabajar en sprints , y este es el primero de tres. En este sprint
no se exige combinar las dos fuentes: cada módulo debe capturar, procesar y persistir su
fuente de forma independiente. En las próximas etapas, expandiremos esta base inicial para
integrar fuentes y agregar nuevas funcionalidades.
2. Requisitos del Proyecto
Requisitos operacionales:
1. El programa podrá funcionar en local y mediante una interfaz de usuario en modo texto
(si fuera necesario informar de algo).
2. Estará programado en Java, usando la versión 21.
3. El proyecto debe estar desarrollado en el entorno de programación IntelliJ.
4. Deben registrarse al menos 5 commits que certiquen el progreso del desarrollo.
Requisitos funcionales:
1. Consumo de fuentes externas (API o scraping):
Seleccionen dos fuentes externas con contenido dinámico , es decir, que su informa-
ción varíe con el tiempo. Se admite el uso de APIs y también de páginas web que
se puedan scrapear . En los anexos encontrarán un listado de opciones. Pueden
proponer otras, pero consulten con el equipo docente para aclarar su idoneidad.
Si optan por scraping , indiquen la(s) URL(s), y el contenido a extraer. Eviten
fuentes que requieran autenticación o que bloqueen el acceso automatizado.
2. Persistencia de Datos:
Cada módulo debe almacenar los datos obtenidos de las fuentes externas en tablas
de una base de datos SQLite.
Los datos deben capturarse periódicamente (por ejemplo, cada hora) y ser guardados
en la base de datos de forma incremental: sin borrar ni sobrescribir lo anterior.
Dado que la información tiene una característica temporal, cada ejecución debe ir
insertando la nueva información (capturas/versiones) conforme cambia con el tiempo.
